## Featured Projects

### 1. RAG Document Chat

**Python | Gemini API | FAISS | Embedding | RAG**

文件檢索與 AI 問答系統，將文件內容轉換為可搜尋的向量資料，檢索相關內容後交由語言模型產生回答。

目前實作與學習內容包含：

- PDF、TXT、Markdown 文件讀取
- 文件切分與 Embedding
- FAISS 向量索引與相似度檢索
- 多文件檢索與 Metadata
- 回答來源引用
- RAG 回答品質評估相關功能持續開發

[View Project](./rag_document_chat)

### 2. GitHub Profile Analyzer

**Python | GitHub API | JSON**

透過 GitHub API 取得公開 Repository 資訊，練習 API 資料擷取、JSON 處理、統計分析與模組化程式設計。

主要功能包含：

- 取得 Repository 資訊
- 統計專案數量與 Stars
- 分析主要程式語言
- 整理高 Stars 專案資訊

[View Project](./github_profile_analyzer)

### 3. AI Resume Reviewer

**Python | Gemini API | PDF Processing | LLM**

使用 Python 讀取履歷文件並串接大型語言模型，產生履歷分析結果，練習文件處理、API 串接與 AI 應用流程整合。

主要功能包含：

- 讀取 PDF、TXT 與 Markdown 文件
- 擷取履歷文字
- 串接 Gemini API 進行內容分析
- 輸出 Markdown 格式的分析結果

[View Project](./resume_reviewer)

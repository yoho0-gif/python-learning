# Project Instructions

## General Rules

- This repository is used for AI self-learning.
- Do not make large-scale changes without explaining them first.
- Do not delete files unless explicitly requested.
- Preserve existing learning projects.
- Prefer small, incremental changes.
- Explain important code changes.
- Run tests after making changes when possible.
- Do not expose API keys or .env contents.
- Do not modify .env files unless explicitly requested.

## Python

- Use the project's .venv environment.
- Prefer Python 3.11.
- Keep dependencies documented.

## Git

- Do not commit automatically unless explicitly requested.
- Before major changes, inspect git status.
- Keep commits focused and descriptive.

## Learning

- When implementing a new feature, explain the architecture first.
- Do not simply provide finished code when the task is educational.
- Point out important concepts that the learner should understand.
